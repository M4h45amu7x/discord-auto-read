# Security policy

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Include the Smart Auto Read plugin version, BetterDiscord version, Discord desktop version, and clear steps to reproduce the issue.

Do not include account tokens, message content, or other private conversation data. Do not file public exploit details before a fix is available.

## Scope

Security reports are especially useful for unintended read acknowledgements, local settings handling, diagnostics privacy, and unsafe interaction with Discord client internals.
